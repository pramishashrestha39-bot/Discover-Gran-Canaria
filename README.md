# Discover Gran Canaria

Author: Pramisha Shrestha

## Project Description
Discover Gran Canaria is an Android application developed using Android Studio and Kotlin. The application allows users to explore Gran Canaria through multiple categories including nature, beaches, culture, food, wildlife, plants, cities and sustainability.

## Features
- Multiple screens
- Navigation between views
- Interactive buttons
- Image slideshow
- FAQ section
- Information cards with images
- Scrollable content

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose

## How to Run
1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle files.
4. Run the application on an Android emulator or physical device.
